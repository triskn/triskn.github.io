Tiiny 项目

为 DeepSeek Harness 做的三个插件

Tiiny 3D

用一张参考图生成带纹理的 3D 模型。在工作台里查看各阶段结果、旋转预览，并导出 GLB 文件。

查看 GitHub 仓库

Tiiny Video

写一段提示词，也可以加一张首帧图。在 DSH 侧栏跟踪视频生成进度，预览成片并保存到本机。

查看 GitHub 仓库

TiinyDecide

把常见的分类判断存成可复用的流程。遇到难判的输入时交给人工复核，并在运行记录里查看模型原始回答和最终结果。

查看 GitHub 仓库
